# Novacal

**A personal calendar and study session manager — my first real attempt at building something that actually worked.**

> ⚠️ **Project Status: Completed** (January 2026)
> I have paused the project for over 90 days, and therefore cannot restart it through the Supabase dashboard. As of January 2026, Novacal's services has ceased.

---

## 📌 Overview

Novacal was my attempt to build a better Google Calendar. It actually helped me plan study sessions around events, habits, and time blocks. It was a proof of concept, a learning project, and my first time building a full-stack app with a real database.

**Notable features:**
- Event creation and management
- Study session tracking tied to events
- Calendar view with day / week / month navigation
- Supabase backend for data persistence
- User authentication

---

## 🧠 What I Learned

- How to structure a React + Supabase app from scratch
- How to handle authentication and user sessions
- How to design a simple but functional database schema
- How to deploy a full-stack project (and later, how to let it get paused)

---

## 🛠️ Tech Stack

- **Frontend:** React (with Vite)
- **Backend / Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth
- **Deployment:** Vercel (frontend) / Supabase (backend)
